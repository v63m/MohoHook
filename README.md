# MohoHook

A lightweight trainer for **PAYDAY 2**, focused on providing convenient in-game tools and customization options through a simple interface.

## Features

* Easy to use
* alot of features
* For PayDay 2!!!! not 3 or The Heist.
* Unlock all allat

## Installation

1. Download the latest release of **MohoHook**.
2. Put the files into **mods**
3. Launch PayDay and you should see in the settings **MohoHook**

## Usage

Launch PAYDAY 2 with MohoHook installed, then use the assigned hotkey to open the trainer.

> **Note:** Available features and keybinds may vary between releases.

## Compatibility

MohoHook is intended for **PAYDAY 2**. Compatibility may depend on the current version of the game and other installed mods.

## Disclaimer

MohoHook is provided for and personal use, if you use DLC guns, you WILL be marked a cheater.
